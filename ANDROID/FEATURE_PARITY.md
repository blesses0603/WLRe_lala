# 電腦版／Android 功能對照

v0.0.6，來源為 `android-development` 內同版桌面功能與共用遊戲核心。手機將多視窗改為各帳號的「開啟角色功能」直式頁面；不是把 Tkinter 視窗直接縮小。切換功能頁保留材料、次數及聊天草稿。

| 電腦版功能 | 手機入口與實作 |
| --- | --- |
| 角色、夥伴、HP／SP、目前活動 | 角色概況，顯示伺服器已同步資料；未知不填假數字 |
| 自動戰鬥／徘徊 | 帳號卡片及概況啟停，沿用獨立核心、四點徘徊與實際狀態 |
| 角色／夥伴完整 AI 規則 | AI與補給設定：同方陣亡、敵HP、低HP／SP、3格回合、5格循環、2格順序；行動類型、已確認特技、目標排序、次階、觀察對象與數值條件、重排行動 |
| 陣亡停機、必要成員 | 一般設定、組隊頁的必要成員，最多4位；未到齊依核心逃跑 |

## 平台差異與驗證範圍

- Windows／macOS 的 Nuitka、BAT 與桌面視窗管理屬於各平台的執行／發布工具；Android 使用 APK／前景服務，不在手機內執行這些工具。
- 電腦版既有限制繼續適用：未知圖紙／活動配方不當作已解鎖；未學會的特技不能當作可用；缺少回覆、材料、設備、位置或回合資料時由核心拒絕／暫停。沒有自行猜測新封包。
- 組隊、製作、煉金、聊天等操作透過私有 IPC 送到相應帳號的同一遊戲核心。只有打開的帳號頁定期取得詳細資料；切到背景停止畫面端輪詢，不停止連線或自動核心。紀錄與圖片快取有界。
- 本機測試使用模擬 runner、真實核心驗證器與 Kivy 視窗；沒有代用使用者帳號對正式伺服器消耗材料或發話。功能操作與多帳號長時間鎖屏仍需真機驗收。
