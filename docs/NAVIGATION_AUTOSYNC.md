# 當前地圖導航自動同步

一般官方資料同步只準備 Runtime／表格，不能當作導航網格已入庫。
舊入口只保存 `on_navigation` 回呼，沒有可點擊按鈕，造成缺庫後無法由主頁完成同步。

修正後，已連線且角色 `world_ready`、官方 Runtime 已就緒且沒有版本安全暫停時，主頁會背景檢查目前場景的同版模型。缺少資料才呼叫既有官方 `sync_model`：下載限制仍是兩個 bundle／32 MiB，保留版本前後核對、Manifest、bundle、CAB/path ID、cache digest 與資料庫完整性檢查。

- 同 Runtime／模型只自動嘗試一次。主頁每次輪詢不讀磁碟、不下載。
- 同模型的自動同步和預覽同步共用互斥鎖；後來的要求重新校驗已入庫資料，不重複下載。
- 換圖、官方 Runtime 更換、斷線、版本暫停或取消時丟棄舊工作結果；已開始的單次 HTTP 讀取可能先結束，下一個下載／發佈檢查點會停止。
- 成功僅顯示「請重新操作，不會自動移動」，不保留目的地、不排入遊戲命令、不自動重試失敗的移動。
- 主頁小地圖下方提供「導航預覽」、「同步導航」、「取消同步」和常駐狀態。手動重試仍受連線／版本安全暫停限制。
- 格式未核對、未知場景、小屋、完整性損壞等情況仍拒絕，沒有舊幾何回退。原有移動幾何／動態障礙限制未改動。

## 驗證

`python -m unittest discover -s tests -p 'test_navigation_autosync.py' -v`

涵蓋缺庫、快取、失敗與手動重試、完整性失敗、併發、換圖、取消、離線／版本暫停、Runtime 更換、關閉、未知模型／版本／小屋、主頁回呼接線及核心同步取消。所有遊戲命令均不執行，測試下載為注入替身。

此工作環境沒有 DISPLAY，尚未驗證真實視窗布局；沒有在使用者桌面啟動 GUI，也沒有實際角色移動驗證。
