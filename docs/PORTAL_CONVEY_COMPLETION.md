# Eve 全場景出入口補齊（v7.1.1 開發中）

## 修復內容

巨鯨島等入口在官方 Eve 有門與傳送效果，卻不在 EveDoorLinks 或 StageMapData。
目前以同版、已驗證的 Eve 門 → PlayerTouch 事件 → Convey 解析目的場景，
以 ScenesData 的倍率換算實際觸碰範圍；不再要求所有入口都先出現在連線表。
這是通用解析，沒有硬填巨鯨島的門編號或座標。

- 實際門 ID、觸碰事件 ID、Convey ID 分別保存；C20-8 仍只送實際門 ID。
- 完整保留每一條條件與落點；多目的地標示為條件出口，由伺服器回覆確認實際場景。
- 只有檢查通過的實際門才能啟用。事件與連線表矛盾時撤銷綁定，不用名稱猜目的地。
- 同場景傳送需等位置確實改變；抵達非候選場景會回報「不同地圖」，不宣稱成功。
- 支援官方零寬／零高的線狀邊界，不擴張其觸碰區域。
- 解析 20-byte 名稱中的長度前綴、驗證群組／Convey 區段偏移及重複 ID。
- Bundle／SQLite Runtime 及歷史預覽共用新解析；可在缺少兩張選用表時解析 Eve 出口。
  SQLite 的官方 Eve 原始 bytes 會重新解析；無須修改內建初始資料庫或建立另一份手填清單。
- 同目的場景仍沿用現有顯示去重。所有門容器的原始資料與未解原因保留於核對資料。

## 巨鯨島案例

航海大地圖 58001 的門 **95**，PlayerTouch **101**，傳送效果指向 Convey **96**，
目的場景 **15093**，原始落點 `(1994,4450)`。觸碰區域換算為
`X=19280～19800、Y=30000～30880`（不含小地圖偏移）。回程門 1～4 亦通過資料綁定。
標記 30381 等原條件保留，不在本機假造完成狀態、不繞過伺服器判斷。

## 測試與驗收範圍

- 完整離線測試：1,533 項，1,378 通過、155 依環境跳過，零失敗。
- 傳送點測試：144 項，137 通過、7 跳過；新增 10 項 Convey 回歸測試全部通過。
- `compileall`、儲存庫嚴格稽核、`git diff --check` 與程式 `--self-test` 通過。

- 傳送點測試包含缺少選用表、條件分支、同場景傳送、實際封包門 ID、
  缺失 Convey、未知場景、錯誤區段偏移、名稱前綴、來源衝突反覆載入與線狀邊界。
- 官方資料解析及綁定數是離線核對；未登入正式伺服器，未將資料成功當成傳送成功。
- 本環境無 Xvfb，GUI 測試依測試套件的環境條件跳過；Windows／macOS CI、
  實際小地圖畫面與正式服進出仍須分別驗收。
- 本分支未合併 main，沒有建立 Release 或 Tag。
