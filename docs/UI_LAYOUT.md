# 介面配置

- 主視窗固定 1280×800；右上小地圖整區 380×320，NPC／怪物清單持續顯示。右下事件紀錄與戰場陣形切換，聊天固定在左下。
- 主頁採兩欄卡片，角色、活動與經驗摘要橫跨兩欄。啟動、關閉與設定入口置於各卡片標題列。
- 組隊採隊伍資料與必要隊員設定雙欄；煉金採材料與執行狀態雙欄。經驗效率分為篩選、摘要與比較表。
- 插畫保留，內容採深色半透明襯底；區塊只畫必要的單層圓角框。文字、按鈕的背景從同一張合成影像擷取，避免標籤形成異色方塊。
- 一般文字 14px、標題與下拉選單 16px、大標題 22px。操作與長清單提供一致間距及捲動控制。
- 彈出視窗統一頁首說明、內容區與底部操作列；保留既有草稿、確認與取消行為。
- 製作項目採每頁 12 個（4 欄×3 列），32px 圖示與收藏、狀態保持可見。右側配方詳情同頁且延伸全高，摘要與材料表固定排版，不提供拖曳分隔，批數／加入按鈕固定在下方；左側集中製作工具列，材料表不提供捲動條，最多五種材料完整顯示；收藏為卡片下方獨立的空心／實心愛心按鈕。
- 小戰場會縮略過長文字；移入單位格子可看完整名稱及 HP，點擊仍僅選取目標。

桌面驗證見 VALIDATION.md；Windows 的字型、正式服狀態與多開效果仍須實機檢視。

自動戰鬥、補給與必要隊員偏好按「帳號＋伺服器」保存，同伺服器跨分流共用；首次沿用最近儲存的舊分流設定。設定載入不自動啟動 AI，未套用的草稿不保存。

自動戰鬥的「補給設定」採 HP 左欄、SP 右欄，上方共用戰後補給啟用開關；每側各 10 格補品與玩家／夥伴門檻，設定資料仍分別保存 HP 與 SP。

「經驗效率」分頁按鈕靠主分頁列右端對齊，內容顯示位置不變。登入視窗只有「登入」操作，固定先驗證帳號後登入，不再提供驗證勾選項。
