# 桌面每日任務助手

## 範圍

「福利」的每日助手把當期伺服器每日目標、可自動／待人工／阻擋原因、
進度與既有服務狀態放在一起。它不是所有任務的一鍵完成器，不建立第二套
排程，也不由畫面推算或回報任務成功。

- 任務名稱與條件沿用當期已驗證官方 Runtime；進度、週期及領取狀態來自 S124。
- 集中管理時間魔方、日／週可領獎勵、組織簽到與捐獻、方舟派遣／一般戰鬥／問答。
- 各項選擇與金幣／星力上限明確套用；登入後沿用既有服務設定，不因開啟助手而增加消費。
- 顯示「已保留」與「伺服器確認已花」兩個數字。保留額度涵蓋已要求的成本，
  包含待確認或結果不明的要求，不等於額外可花的餘額。
- 未支援條件列為待人工；煉金、製作、副本等不由助手建立材料、配方或開戰授權。

## 執行與停止

助手設定經網路執行緒集中驗證，全部有效才套用；無效設定不會留下部分啟用。
沿用現有 `service_scheduler.advance_services` 的單一服務排程與共享互斥。
開啟、選取、重新整理與關閉介面不發送遊戲操作；關閉視窗不等於停止。
「停止後續操作」停用助手涵蓋服務的自動接續，已送出的要求仍等待原服務確認或逾時。
重新啟用不清除 pending、uncertain、已保留或已確認額度，也不重送未知結果。

組織金幣額度仍以既有連線／明確伺服器消費日更規則管理；方舟星力額度仍以
本次登入為界，跨日不自動加額。不同角色、官方版本或每日群組切換沿用各服務
現有隔離檢查。界面沒有另存可跨角色重放的授權。

未知獎勵、背包容量不足、問答無可靠答案、錯答、逾時或非預期扣款仍由既有
服務安全停止。助手不解除導航正式移動安全閘門、不擴充小屋操作、不修改 Android。

## 驗證界線

離線測試與 CI 只能證明程式與合成封包路徑；不能代替正式服驗收。
尚未透過真實角色確認登入後同步、已領項目、實際扣款、跨日／斷線重連、
背包不足後恢復及正式服問答。沒有建立安裝包、合併 main 或發布版本。

人工驗收時先把金幣／星力上限設為 0，確認沒有消耗操作；再逐項授權，
核對伺服器進度與實際餘額。要求送出後立即停止，應只完成已送要求的確認，
不得送下一筆。重複套用、關閉重開與全域暫停也應維持同一限制。
