# 遊戲式特技介面

「包包與特技 → 全部已確認特技」採用三欄配置：

- 左側角色／夥伴列表，保留夥伴槽位編號；官方頭像尚未同步時不猜測。
- 中央原始官方圖示、技能等級／上限、SP、官方說明、適用武器、使用條件與來源。
- 右側圖示技能清單，可用全部、物理、魔法、輔助、被動、其他篩選，也支援原有搜尋。

沿用 LaLa 深藍玻璃風格，而非複製遊戲的淺色外框。只列伺服器已確認的技能與目前裝備附帶技能，沒有新增學習、升級或快捷列指令。技能等級來自伺服器；不把等級比例冒充熟練度進度。

點選角色、技能、分類或搜尋只更新顯示，絕不自動施放。原有施放按鈕仍經過登入、戰鬥、武器、SP、目標與最新伺服器狀態檢查。離線與場外可以檢視，但不能施放。換角色、篩選移除選取技能或資料更新後，不保留無效操作對象。

圖示來源與 SQLite 格式見 [官方技能圖示](OFFICIAL_SKILL_ICONS.md)。描述由官方 TextData 解析；未同步或缺失明確顯示，不捏造效果。

## 驗證範圍

新增測試涵蓋分類搜尋、重複同名夥伴、切換與移除角色、選取保留／失效、不可施放狀態、反覆操作與視窗銷毀、720p 排版、原始圖示完整性及損壞檔案。

介面測試使用離線固定資料，不代表正式伺服器技能施放或升級驗收。本 PR 不改動自動戰鬥規則或新增遊戲操作。
