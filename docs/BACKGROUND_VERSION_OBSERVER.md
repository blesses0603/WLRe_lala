# 桌面背景版本觀測與安全暫停

## 驗證生命週期

每次程式啟動先完成原有官方來源、Manifest、Bundle、Runtime 與資料庫內容校驗，建立本次程式執行的完整驗證基準。背景結果不能改寫這個基準，也不會冒充新的完整校驗。

之後背景預設每 300 秒讀取 ResourcePath_PC.dat、DataPackage.version、MainPackage.version，以及本機 SQLite 的有效版本識別。只有官方識別、資料庫識別與本次完整驗證基準三者相符，才可把這次觀測視為新鮮的登入條件。完整校驗本身可提供初始識別證據。觀測過期時，按登入只補做輕量查詢，不每五分鐘重建 Runtime；查詢完成後仍由使用者登入，不自動重連。

這是輪詢，不是即時推播；網路或 CDN 延遲可能使變更較晚才被發現。版本相符只代表識別相符，無法偵測同版號內容被替換、損毀或尚未觀測到的遠端變更。重開程式、手動完整重驗、異常後恢復，仍走完整內容校驗。

## 查詢與併發限制

- 正常觀測最多三次小型 HTTPS GET；無 Manifest／Bundle 下載、Runtime 解析或資料庫寫入。
- 每請求預設 timeout 12 秒，共用 30 秒 elapsed budget；不疊加重新導向或重試。
- 只允許一個背景觀測工作。完成後排下次查詢，失敗退避 60／120／300／600 秒。
- 輪詢間隔可於畫面調整，範圍 60–3600 秒；環境變數 WLRE_VERSION_OBSERVE_INTERVAL_SECONDS 可設定啟動預設。
- 完整重驗、關閉或更新世代後的舊結果不採用。socket timeout 不等於能硬取消作業系統 DNS 或 SQLite 呼叫，背景工作不得阻塞 Tk。
- 使用既有 ResourcePath PC 映射解析規則，不另外推測官方發布版本。

## 不一致、失敗與連線中的行為

任何查詢失敗、官方／資料庫識別不一致、資料庫未知，或兩者一起偏離本次完整驗證基準，都會撤銷舊登入授權，強制顯示「資料準備與官方版本檢測」。之後即使輕量查詢恢復相符，也不能直接重新放行。

已連線時不強制斷線、不熱替換全域 Runtime。連線專屬安全暫停會在網路執行緒的安全邊界阻擋新的資料依賴操作與自動事件接續；保留接收伺服器回覆、心跳及已送出要求的確認。已開始的同步派送批次和已送出的要求不能撤回，不能把暫停說成交易已取消。清除外部 Event 亦不恢復該次連線。

檢測畫面提供輕量重查與安全中斷。完整校驗必須等連線結束後才能進行，通過後才能建立新的登入條件。關閉視窗依原本流程安全退出程式，不解除封鎖。一般斷線仍返回登入頁；因背景異常而暫停的連線結束時，改留在完整檢測畫面。

## 驗證範圍

離線測試須涵蓋首次完整校驗、冷／暖版本觀測、相符／不符／未知、逾時、SQLite 身分變動、與完整基準不一致、單一工作、舊結果、關閉、逾期只補輕量查詢、重連及安全暫停。網路測試使用合成封包與本機替身，不等同真實官方服長時間連線驗收。
