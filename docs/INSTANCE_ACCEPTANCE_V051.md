# v0.5.1 副本／協力正式伺服器驗收清單

> 此清單是人工實測步驟，不是已通過紀錄。通過三平台原始碼 CI 不代表遊戲正式伺服器驗收成功。正式 Release 保留 v0.6.0。

## 安全前置條件

- 使用最新 main 原始碼預覽版：Windows 執行 `run_client.bat`，無須編譯或下載新 Release。
- 每次實測前先停用自動戰鬥、徘徊、製作、煉金及遠征；登入後等待角色與世界資料同步。
- 準備可靠同步的背包和至少四個空位。協力票券或點數花費由玩家自行評估，任何扣點操作不得自動重送。
- 獎勵自動領取初始狀態必須為**關**；只有玩家明確啟用後才對免費獎勵生效。
- 首次遇到斷線、超時、未知回覆或重複扣費疑慮，**停止該項實測**，重新登入確認，不要強制重試。
