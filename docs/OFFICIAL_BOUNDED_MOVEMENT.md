# 官方平面陸地受限移動與四點徘徊（PR 評估分支）

使用者要求移除「尚未完成實際移動驗證」的一律禁止門檻。這一階段以同版官方資料建立可檢查的受限執行契約，而不是修改預覽旗標假稱正式服已驗證。尚未合併或發布，沒有操作使用者角色或連線正式服。

## 來源與路徑契約

`OfficialMovementAdapter` 只接受目前官方 Runtime 的完整 identity、場景表與同版 navigation.sqlite3。原有 Manifest／Bundle／cache hash 校驗仍有效；不讀三份舊seed、不自動下載，資料缺失或版本未知就停止。

只支援一般地圖的陸地通行標籤、同一平面、沒有重疊樓層歧義的路徑。房屋、4個退化模型、坡面、海上／飛行、不明場景與過期障礙狀態仍拒絕。不能用指定高度選掉多層歧義。每條線段完整包含於官方可通行走廊，且不能逆穿序列化單向連線；檢查包含途中交疊樓層，而非只查兩個端點。

路徑保留 `can_send_packets=false`、`live_movement_verified=false` 與動態障礙未驗證標記。Movement只對真正的adapter，驗證它自己剛產生、內容未變、版本和導航狀態仍一致的路徑契約；不接受把同名字串或布林塞進普通預覽字典。原合成測試用明確注入的converter契約保留，不是產品舊seed後備。

## 執行界限

- 原始步速上限3.5世界單位／秒；至少0.2秒才可產生下一個位置報告，每次最多1包、不追趕補發、不重複相同座標。
- 每次最多到下一個waypoint，不能用一包直線跨過拐角。重新驗證實際四捨五入後發包座標之間的線段、方向、平面及速度。保留15 Int3的四捨五入餘量，實際每步不得超過700 Int3（70封包座標單位）。
- 一般移動每段路線最多20世界單位、512路徑點、128位置報告，並有依路長計算的逾時上限，最長30秒。
- 四點徘徊沿Lua順序，以中心偏移(-2,-1)、(-2,2)、(2,-1)、(2,2)世界單位。啟動前預檢首段、其餘三段與閉合段；整條路徑須留在中心3世界單位內，每段不超過8世界單位。
- 來源、角色、場景、戰鬥、事件、導航版本／stale、權威起點與位置狀態均仍檢查。收到伺服器校正／停止、不明狀態、逾時或幾何拒絕時不自動重送；徘徊顯示中斷並需使用者重新啟動。
- 戰鬥／事件原有暫停流程保留。重新啟動會重新取得當期來源，不沿用過期adapter。
- adapter最多處理10,000個mesh面，路徑與全mesh檢查配額2,000,000次，超限安全拒絕。

一般點選移動、NPC靠近與其他使用同一Movement服務的入口也受到上述20世界單位／平面等限制。這不是將所有移動功能宣稱完整可用；長距離目的地需要另行設計分段策略，本階段不自動拆段繞過限制。

## 驗證方法與風險

合成回歸包含四點循環、實際scheduler的outbound狀態轉換、同tick不重送、延遲不補發、速度／半徑／距離限制、離開走廊、單向邊、途中樓層、不可走標籤、損壞DB、換版、導航失效、伺服器校正／停止與mock transport。沒有使用者帳號或遊戲transport。

真實官方cache測試每模型只取「最大陸地三角形中心、轉換並四捨五入為封包座標」一個測試中心，進行四點預檢及首圈mock執行；不能拿模型一個位置成功當成該模型任意位置可走。拒絕原因應逐模型保留。

官方靜態mesh並不包含已驗證的全部執行期碰撞、角色實體半徑、伺服器接受／抵達語意。已觀測到障礙變更會停止，但沒有觀測到變更不代表沒有動態障礙。本機路徑完成仍明示「尚無伺服器位置確認」，不當成正式抵達；上述旗標維持未驗證，使用者移除的是一律禁止門檻而非這些事實。新功能若之後採用，仍有撞牆、伺服器校正或安全停止風險。

### 558模型離線實檔結果

使用相同官方1296身分與實際cache，每模型1個中心：425個完成首輪四點mock循環，133個預檢安全拒絕。共產生9,532個mock C6-1物件，最大實際步距69.4622封包座標單位（上限70），最大中心半徑289.9276（上限300）；每tick最多1個、重複tick不重送、舊seed與socket存取0次。133個拒絕分為8無陸地節點、28非平面、73目標不允許步行、15路線過長、8超中心半徑、1座標越界。

[逐模型抽樣及實測程式hash](official_bounded_movement_1296_samples.json)。這不是425個模型全區域可走，也不是正式服成功。4個退化模型本來就不在558支援名單內。
