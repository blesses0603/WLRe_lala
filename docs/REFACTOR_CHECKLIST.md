## 第 03 項驗收範圍

- 共用 1280×800 插畫設計畫布，彈出視窗按同一座標系裁切，避免背景重新縮放。
- 區塊面板和控件取樣只在父容器有效範圍繪製，避免越界色帶。
- 取消一般彈窗與自訂裝飾重疊的額外青色外框，主視窗保留原樣。
- 固定大小的彈窗使用螢幕可用範圍縮限、置中，並保留其他呼叫介面。
- 新增主題與視窗幾何回歸測試；正式遊戲封包與各業務邏輯不變。

本次未變更主儀表板 1280×800 固定版型，也未完成原生高 DPI 動態縮放或實機截圖校正。

- State.apply 保留唯一入口；先計算封包數、依原順序更新九個服務，再進入互斥的本地事件路由，最後觀察效率。

## 第 07 項驗收範圍：網路封包、指令及經驗效率

- 手動網路命令在分派前驗證 type 欄位；無效資料只產生安全拒絕事件，不洩漏整份命令內容。
- C50、C23 與移動 C6-1 的本機已送出記錄改由純函式整理；不完整的候選負載先拒絕，成功送出後才更新本機紀錄。
- XOR 封包拆框、S8／S20 解碼、活動門檻、服務指令與線上封包格式維持原樣，無自動重送。
- 經驗效率只依據本機角色及已知夥伴的 S8-1／S8-2 EXP 回覆與完成戰鬥，技能經驗不參與。
- 閒置夥伴不再因其他單位戰鬥而失去近 10／30 場有效樣本；已參戰但缺少 EXP 變化時不自行補 0 或跨場估算。
- 已確認的等級／階段可移除過去的推估標籤，升級門檻計算維持原有 EXP_Monitor 參考曲線。
- 新增指令拒絕、封包實際送出時點、分段封包、技能 EXP 排除、玩家與坐騎樣本間隔測試。線上伺服器 EXP 事件順序仍需實機驗證。

## 第 08 項驗收範圍

- 物品圖示 ZIP 按需讀取，跨背包／製作／補給視窗共用解碼像素，最大 8 MiB 與 128 筆，採 LRU 淘汰；不共享 Tcl/Tk 圖片物件。
- 半透明背景快取只在面板、父容器邊界或窗體畫布變動時失效；一般控制項幾何改變不讓全部 UI 圖片重新生成。
- 保留既有 UI 事件更新節流、網路單一寫入者與 State 快照安全行為。無需更動任何遊戲封包或經驗效率計算。
- 新增跨視窗圖像生命週期、壓縮檔解碼次數、快取記憶體上限和局部背景失效的自動回歸測試。
- 以上屬於減少重複運算與有界快取，無宣稱正式遊戲中的固定 FPS 加速百分比；在不同 DPI／解析度及長時間連線仍需人工量測。
