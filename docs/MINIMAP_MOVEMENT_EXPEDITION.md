# 小地圖操作與遠征恢復

## 行為

- 小地圖單擊空白區域會選取座標並畫出黃色目的地，不會送出移動封包。雙擊會交由既有 walk 命令與 Movement 執行導航，沿路送出 C6-1；本機走完不冒稱伺服器確認抵達。
- 傳點仍依官方名稱／目的地／位置校準與門索引判定可用性；移除僅因 Runtime 有動態 Catalog identity 就停用的條件。可用傳點可手動點擊或雙擊觸發 C20-8，既有 pending 防重送保留。
- 官方場景與資料庫導航必須逐場景比對模型、寬高及小地圖位移。相符才使用資料庫的圖原點與導航網格；不相符仍顯示官方投影及圖片，可選座標，但實際移動明確報錯。未新增或冒稱已取得當次官方導航網格。來源更新會停止原路徑。
- 手動啟用遠征後，等待遠征／駐紮所同步、戰鬥結束或背包／好友度補給恢復，不再因這些暫時條件遺失啟用狀態。登入本身不會自動啟用。
- 選隊不再漏掉好友度高於使用者門檻、但低於任務消耗的夥伴；派遣前補到兩者較高值。概要顯示實際等待原因。未確認消耗逾時仍停止並禁止重送。

## 回歸驗證

新增 15 項案例覆蓋單擊、雙擊到 Movement 封包、目標繪製、範圍、幾何不符、來源更換、12170 資料庫網格路徑、動態傳點單次觸發、遠征等待／恢復與實際 scheduler 派遣路徑。同步更新既有受影響案例。
