# 自動戰鬥／徘徊／遠征 Play / Pause 圖示（PR #57）

本次來源為使用者提供的兩張《飄流幻境 RE》風格 PNG：

| 按鈕用途 | 來源圖片 | 專案資源 |
| --- | --- | --- |
| 功能未啟動，點擊可開始 | `Btn_Play__c9f039ec29_8760418811135042524.png` | `Auto_Play.png` |
| 功能已啟動，點擊可停止 | `Btn_Pause__c9f039ec29_1469622244222669506.png` | `Auto_Pause.png` |

原圖為 71×71 RGBA，專案內為**保留透明度並以 Lanczos 縮放**
的 28×28 PNG，以維持既有首頁資訊卡片的高度與按鈕一致性。

`ui/automation_control_icons.py` 共用載入：

- 主頁 `HaloButton`：自動戰鬥、自動徘徊、自動遠征。
- 遠征設定視窗：現有的「啟動自動派遣／停止」兩個操作鍵。
- 未連線、啟動未經伺服器狀態回覆時，一律顯示 **Play**；
  `auto_battle/roaming/expedition.enabled=True` 後顯示 **Pause**。
- 當狀態再次變成未啟動時回復 **Play**；不會在按鈕點擊後立即
  假設伺服器已成功處理。
- 保留既有事件指令、UI 可用性、鍵盤操作、原始文字屬性及
  彩虹邊框；缺圖時安全退回既有文字按鈕。
- 沒有變更任何封包、自動化配置、交易或相關安全檢查。

圖示來自使用者直接提供的 PNG；未獨立驗證它們在官方
1275 Bundle 中的 Sprite / Texture2D 資產路徑與 hash。
