目前版本：v0.5.0

本次更新（v0.5.0）

- 正式版本提升為 v0.5.0；Windows 與 macOS 打包版本由 `wlre.__version__` 統一產生。
- Windows GitHub Actions 預設允許 C 編譯快取，並加入跨次建置的快取還原與保存設定；編譯診斷模式維持可選。
- 發布時需先建立與程式版本一致的 `v0.5.0` 標籤，推送標籤後才會執行三平台建置。

上一版更新（v0.4.21）

### 新增

- 重新整理全介面版面：保留插畫與青色圓角風格，內容區加入深色襯底，文字與控制項沿用同一位置的合成背景，提高可讀性。
- 主頁改為雙欄資訊卡；角色、目前活動與經驗效率使用寬卡，自動戰鬥／徘徊及各功能入口放在卡片標題列。
- 組隊左側集中隊伍操作、成員與邀請清單，右側固定必要隊員設定；兩個清單加入各自的捲動控制。
- 煉金改為左側材料表單、右側執行狀態與開始／停止操作；經驗效率以摘要區、進度與比較表分層顯示。
- 登入、AI 規則與行動編輯、包包／特技、補品選取、自訂製作清單及導航採用共用標題與說明；主要確認操作集中於操作列。
- 清單統一捲動配置；小戰場長名稱縮略並可移入查看完整名稱與 HP，保留原有選取行為。
- 維持 1280×800、380×320 小地圖與常駐 NPC／怪物清單，以及目前的 14／16／22px 字級。

- 主分頁精簡為主頁、組隊、煉金、製作、經驗效率；移除戰鬥／徘徊分頁，自動功能沿用主頁按鈕及 AI 設定入口。
- 右下新增「事件紀錄／戰場陣形」切換分頁；必要隊員名單移至組隊，保留儲存、套用及檢查功能。
- 右上小地圖整區固定為 380×320（含 NPC／怪物清單），清單保持展開並自動跟隨目前地圖。
- 全介面字體縮小 2px：一般文字 14px、18px 標題與下拉選單改 16px、大標題改 22px；同步縮小按鈕留白與表格列高，內容外框沿用共用樣式。

- 主頁自動戰鬥新增「AI設定」，自動戰鬥與自動徘徊可直接「啟動／關閉」；啟用時顯示動態七彩光環，隱藏分頁時暫停動畫。

- AI、補給與必要隊員設定依帳號及伺服器儲存（同伺服器跨分流共用），切換帳號可自動還原，不會自動啟動 AI。
- 點選製作項目直接更新右側配方詳情，保留搜尋及頁碼；排程顯示目前項目、剩餘時間與進度。
- 加入每個程式獨立的診斷紀錄，只記錄介面耗時、事件積壓及錯誤次數，不含帳密、封包或聊天內容。紀錄位於 `%LOCALAPPDATA%\WLRE_LaLa\diagnostics\`；每檔 1 MiB，保留 2 份輪替備份。
- 「製作」分頁改為圖示介面，保留設備分類、收藏、搜尋、自訂清單與排程操作。
- 製作項目每頁顯示 12 個物品（4 欄×3 列），使用 32 像素圖示；製作項目與配方詳情同頁顯示，保留右側地圖及下方聊天。
- 主頁狀態總覽：集中顯示角色與夥伴 HP／SP、目前活動、AI、徘徊、補給、煉金、家具製作、隊伍及經驗效率。
- 總覽提供各功能入口，完整經驗統計獨立為「經驗效率」分頁。

### 修正

- 配方材料圖示取消樹狀縮排並靠左，縮小材料表標題列留白；鎖定欄位分隔線，避免拖動改變欄寬，保留正常列選取。

- 「經驗效率」按鈕移至主分頁列最右端，分頁內容維持原區域；組隊提示數量更新後仍保留右側對齊。
- 登入固定先驗證帳號再登入，移除驗證勾選項，並將「驗證並登入」簡化為「登入」。

- 配方詳情固定延伸全欄高度，移除上下拖曳分隔及材料表捲動條；壓縮摘要間距，完整顯示五種材料。材料名稱欄固定為 76px，可用／需求數量置中。

- 製作頁的自訂清單、進入自家帳篷與製作排程集中左側；配方詳情延伸整個製作區高度，摘要與材料表固定排版，不提供拖曳分隔，批數與加入操作固定在下方。

- 製作頁改為設備、12 項物品與右側配方詳情同頁顯示，取消詳情分頁；材料採無捲動條的固定表格，批數與加入操作保持可見。
- 收藏愛心改為卡片下方獨立按鈕，使用固定的空心／實心圖示，避免字型差異與卡片邊角重疊。

- 自動戰鬥的 HP／SP 補給合併為「補給設定」一頁，左側 HP、右側 SP，共用啟用戰後補給開關；兩側各保留 10 個補品格與獨立門檻。主頁補給入口直接開啟合併頁，既有帳號設定格式不變。

- 自動戰鬥設定改依「帳號＋伺服器」保存，地球／水星分開，同一伺服器的分流共用；首次載入沿用該伺服器最近儲存的舊分流設定並保留原檔。自訂連線依主機與連接埠區分。

- 配合加寬後的操作區，製作項目由每頁 6 個增加為 12 個（4 欄×3 列），保留 32px 圖示、收藏、製作狀態、搜尋與翻頁。

- 連續煉金改為結果、入包與扣料確認後至少間隔 1 秒才續送，避免第一輪完成後立即送下一筆；戰鬥或補給等待後亦保留穩定間隔。逾時會顯示缺少哪種確認，不會重送未確認的煉金。正式服改善情況仍待實機複測。

- 「戰場陣形」「自動徘徊」「自動戰鬥」各自保留同樣式的單層內容外框，移除三者共同外層的重複框線。

- 主頁、戰鬥／徘徊、組隊、煉金、製作、經驗效率統一保留單層圓角外框。主頁啟動按鈕改用共用標準按鈕，與其他操作按鈕使用相同尺寸、留白及圓角；啟用時保留七彩邊線。

- 保留小地圖、聊天、事件紀錄及功能分區的基本外框；戰鬥／徘徊保留單層圓角外框，不再疊上「戰場」與內部分頁框。

- 簡化各分頁及功能視窗的重複外框：戰鬥／徘徊移除多餘「戰場」容器，分頁內容採無邊框；各區保留標題與間距及基本外框，移除重複包框。無標題規則區不再預留標題高度，戰鬥格線與操作控制項邊線保留。

- 七彩光環改用固定的完整圓角遮罩，動畫只更新顏色；移除細線接縫與銳化縮放的外側彩色毛邊，更新影像後排程按鈕重繪。

- 主頁小地圖固定自動跟隨角色目前地圖，移除跟隨勾選、導航邊界、載入及地圖選單；逐圖核對保留查閱，不再切換主頁預覽。

- 改善七彩光環卡頓：更新間隔由 100ms 改為約 16ms，依實際時間流動；直邊與圓角均勻分色，並重用邊線幾何資料。

- 七彩光環改為沿按鈕本身的圓角邊線流動，移除外圍矩形彩框；關閉時還原原本邊線。

- 修正主頁啟動按鈕外圍的黑框，光環容器改用對應位置的背景插畫。

- 「Lua 規則自動戰鬥」簡化為「自動戰鬥」，設定視窗改名「自動戰鬥設定」。
- 移除小地圖的「進階導航」按鈕。

- 多開首次啟動共用依賴環境鎖，避免同時建立環境或安裝套件。
- 打包前先驗證專用環境的 pip；無法啟動時使用基礎 Python 重新建立該打包環境，再重新安裝依賴，不改動遊戲設定。
- 重複打包沿用已驗證依賴，仍檢查套件一致性及必要功能；需求檔變更會重新安裝。使用 `build_nuitka.bat --upgrade-deps` 可強制更新。

- 修正多開同時儲存帳號記憶造成覆蓋，以及收藏共用暫存檔衝突；程序中斷後會自動釋放檔案鎖。
- 背景／最小化視窗降低顯示更新頻率，隱藏分頁延後重繪；聊天與事件紀錄有界暫存，回到前景再更新。連線及遊戲指令照常處理。
- 帳號變更後，舊的 AI 設定視窗不能誤將草稿套用到另一個帳號。
- 功能入口名稱簡化：「自動煉金」改為「煉金」，「家具製作」改為「製作」。
- 移除「經驗效率」分頁中的「包包／特技」按鈕。
- 簡化座標與移動提示，移除本機同步、伺服器確認及來源註記，保留地圖、座標與移動狀態。
- 降低多開登入主頁後的介面負載：非聊天事件不再重掃聊天名稱，事件分批處理，避免阻塞按鈕操作。
- 合併重複的介面狀態快照，每個程式獨立更新；保留逐筆封包與事件處理，斷線立即送出最後狀態。
- 移除狀態文字雙擊查看全文及額外詳情視窗。
- 校正登入、AI、補給、包包、製作、導航與表情視窗的尺寸及置中位置，限制在 1280×800 桌面範圍內。
- 調整自訂製作清單欄寬，避免最後一欄超出可視範圍。
- 主視窗固定為 1280×800；加寬左側操作區、縮小右側地圖，聊天及事件紀錄固定於底部。
- 狀態總覽改用單列排列，取消上下捲動條，避免標題及按鈕擠掉狀態文字。
- 保持透明背景，修正聊天與事件紀錄標題和內容重疊。
- 修正地圖清單擠壓換圖及核對按鈕的問題。
- 區分資料未同步與零值，離線時標示為最後收到的資料；必要隊員判定不計入附近玩家。
