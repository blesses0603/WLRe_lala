# 更新紀錄

## 尚未發布 — 2026-10-17

### 新增

- 主頁改為固定卡片式狀態總覽，集中顯示角色與夥伴 HP／SP、目前活動、自動戰鬥、徘徊、補給紀錄、煉金、家具製作、隊伍及經驗效率摘要。
- 從總覽直接前往 AI、徘徊、組隊、煉金、家具製作與經驗效率分頁，並提供包包／特技及補給設定入口。
- 明確區分未同步資料與零值，顯示補給待確認或結果不確定的原因；離線時標示資料為最後收到的狀態。
- 必要隊員摘要沿用既有隊伍判定，附近玩家不計入隊伍成員。
- 新增 6 項總覽測試，涵蓋未同步與零 HP、離線狀態、補給不確定性、必要隊員、戰鬥角色 HP 及空白狀態。

### 調整

- 主視窗固定為 1280×800，不提供縮放。
- 狀態總覽取消上下捲動條，改用固定卡片排列；長文字自動縮略，可雙擊內容查看完整狀態。

- 完整經驗統計移至獨立「經驗效率」分頁，主頁保留精簡摘要。
- 總覽沿用現有狀態快照與功能模組，不新增自動登入、伺服器連線或操作指令。
- README 補上狀態總覽說明與最新測試結果。
